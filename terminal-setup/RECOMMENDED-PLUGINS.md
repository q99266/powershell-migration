# 推荐的 PowerShell 插件与模块清单

本文档列出了用于增强 Windows Terminal 体验的推荐插件。这些模块已集成在 `setup-terminal-en.ps1` 和 `setup-terminal-cn.ps1` 脚本中，会自动检查并安装。

## 1. 核心模块（脚本自动安装）

| 模块名称 | 功能描述 | 核心亮点 |
| :--- | :--- | :--- |
| **PSReadLine** | 高级命令行编辑 | **预测性智能感知** (类似 ZSH 的自动补全) |
| **Oh My Posh** | 提示符引擎 | 自定义主题和 Git 状态图标显示 |
| **Terminal-Icons** | 文件与文件夹图标 | 为 `ls` / `dir` 命令输出添加图标 |
| **z** | 目录快速跳转 | 使用 `z <文件夹名>` 快速切换到常用目录 |

## 2. 进阶建议（可选安装）

| 模块名称 | 功能描述 | 推荐理由 |
| :--- | :--- | :--- |
| **Fzf-Powershell** | 模糊搜索器 | 极速搜索历史记录和文件 |
| **Posh-Git** | Git 状态集成 | 在提示符中显示更详尽的 Git 状态信息 |
| **Get-ChildItemColor** | 彩色输出增强 | 为不同文件类型添加更丰富的配色 |
| **Crescendo** | CLI 封装器 | 将原生命令行工具包装成 PowerShell 对象 |

## 3. 推荐辅助工具

- **fzf**: 命令行模糊搜索工具。
- **bat**: 支持语法高亮和 Git 集成的 `cat` 替代品。
- **lsd**: 带有图标和配色的现代化 `ls` 替代品。
- **ripgrep (rg)**: 性能极其强悍的搜索工具（替代 grep）。
